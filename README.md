🚀 How to Use
Open any webpage in your browser (e.g., Chrome, Edge, Firefox).

Open DevTools / Inspect by pressing F12 (or right-click anywhere on the page and select Inspect).

Click on the Console tab at the top.

Paste the entire code script into the console and press Enter to launch the menu!
